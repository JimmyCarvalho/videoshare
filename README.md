# videoshare

Página de compartilhamento dos vídeos de lançamento do RCO Dash, publicada pelo GitHub Pages.
Os vídeos e o catálogo ficam cifrados (AES-GCM, chave derivada da senha por PBKDF2); sem a senha a página
só mostra o campo de senha. O gerador está em `rco-dash/fonte/compartilhar` no repositório de origem.
